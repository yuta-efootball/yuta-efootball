# eFootball タレントデザイン用選手データ v2.9.6

## 内容
- players.csv：v2.9.5の57件に、Game8のみを参照して確認したTPカード30件を追加。合計87件。
- 今回追加分は、Game8掲載の基本情報、最大総合値、初期能力値25項目、選手特徴（逆足頻度・逆足精度・調子の波）、所持スキルを確認して収録。

## データ方針
- 本バージョンの追加30件について、数値を推測して補完していない。
- 最大総合値はGame8掲載値、能力値はGame8の「初期値」を使用。
- talentPointsは0、attackTypeは「未選択」、playerTypeは「トレンド」。
- ブースターはGame8掲載値を使用。
- ownedBoostersが「-」のカードは「-」をそのまま収録。
- skillsはGame8の所持スキルを「|」区切りで収録。

## 参照元
追加30件はGame8（https://game8.jp/efootball）の各選手ページのみを参照。

## 注意
Game8の掲載内容が更新された場合、本CSVの値との差異が生じる可能性がある。
