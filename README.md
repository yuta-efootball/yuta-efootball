# eFootball タレントデザイン シミュレーター v2.9

## 修正内容

### 選手CSVの項目追加
`players.csv` に以下の2列を追加しました。

- `playerType`：選手タイプ
- `skills`：所持スキル

既存選手について今回確認できていない情報は `未設定` としています。推測による補完はしていません。

### トレンド選手のタレントポイント
`playerType` が `トレンド` の選手は、JavaScript側で `talentPoints` を自動的に `0` として扱います。
これにより、トレンド選手はタレントデザインによる育成ができません。

### ペトル・チェフを追加
Game8の「EPペトルチェフ（チェルシー/05-06）」を `players.csv` に追加しました。

- `cardName`：EPペトル・チェフ（チェルシー/05-06）
- `attackType`：未選択
- `playerType`：エピック
- `talentPoints`：56
- タレント振り分け：反映していません（各群0の初期状態）
- 所持スキル：低弾道パントキック / GKロングスロー / PKストッパー / GKディレクティングディフェンス / キャプテンシー
- ブースター：ゴールセービング / キャッチング

### `liveLinkTargets` 列
`liveLinkTargets` は引き続き使用しません。今回の `players.csv` からも削除しています。

## 維持している内容

- 最終能力値カードの上下余白 `0.15em`
- 選手データはGitHub Pages上の `players.csv` を正本として読み込みます。
- 監督・監督適性・ブースターについては、従来どおり外部JSONを優先し、読み込み失敗時はフォールバックデータを使用します。
- 選手CSVの読み込みに失敗した場合、選手フォールバックには切り替えません。
