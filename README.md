## v1.3のタレント振り分けルール

パラメータ群への「振り分け値」と、その振り分けによる「能力上昇値」を一致させます。

- 1振り → 能力 +1
- 2振り → 能力 +2
- 3振り → 能力 +3
- 4振り → 能力 +4
- 5振り → 能力 +5
- 6振り → 能力 +6
- 10振り → 能力 +10
- 16振り → 能力 +16

したがって、パラメータ群に `k` ポイント振り分けた場合、能力上昇値は `k` です。

## タレントポイント消費ルール

能力上昇値を振り分け値と一致させる一方、タレントポイントの消費ルールは変更しません。

- 1～4 → 1TP / 1振り
- 5～8 → 2TP / 1振り
- 9～12 → 3TP / 1振り
- 13～16 → 4TP / 1振り
- 以降も4ポイントごとに必要TPが1ずつ増加

例えば10振りの場合、能力は+10ですが、消費TPは以下です。

`1×4 + 2×4 + 3×2 = 18TP`

## v1.3で確認する項目

- 4振り → 能力+4
- 6振り → 能力+6
- 8振り → 能力+8
- 10振り → 能力+10
- 12振り → 能力+12
- 16振り → 能力+16
- 10振りの消費TP → 18TP
- 0振り → 能力+0、消費TP 0
- 複数のパラメータ群へ振り分けた場合、それぞれの振り分け値がそのまま所属能力へ加算される
- 「ジャンプ」はフィジカルとGK1の両方の振り分け値が加算される

## GitHubへの更新方法

1. ZIPを解凍する。
2. `script.js` と `README.md` の2ファイルをGitHubリポジトリへアップロードする。
3. 既存の同名ファイルを置き換える。
4. Commitする。
5. GitHub Pagesの公開URLを再読み込みする。

v1.2で変更した `config.js` と `icons.svg` はそのまま残します。
