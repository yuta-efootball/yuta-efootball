## 1. ブースターUI

### 通常ブースター
通常ブースターを2枠に整理し、それぞれのプルダウンの下に上昇値ボタンを追加しました。

- +1
- +2
- +3
- +4

同じ通常ブースターを2枠で選択した場合も、各枠の上昇値を個別に設定できます。
ボタンは択一式で、同じボタンを再度押すと未選択に戻ります。

### エッジブースター
エッジブースターにも上昇値ボタンを追加しました。

- +6

将来、ゲーム仕様変更で上昇値を追加する場合は、HTMLにボタンを追加するだけで拡張できる構造です。

### 追加ブースター
従来どおり、選択したブースターの対象4能力に対して+1/+2/+3を適用します。

## 2. アイコン

- シュートは従来のアイコンを維持。
- パス、ドリブル、瞬発、脚力、ディフェンスは添付されたアイコンから外側の背景を除去し、黒い図形部分を使用。
- フィジカルは従来のくの字アイコンを90度右回転。
- GK1～GK3はグローブ＋白抜き数字の構成を維持。

## 3. カラー

能力値90以上、および「最高」の色を以下に変更しました。

`#21C08B`

## 4. コンパクトUI

スマートフォンでのスクロール量を減らすことを目的に、全体のフォント、余白、カード間隔、ボタンサイズを大幅にコンパクト化しました。

特に能力配分はスマートフォンで2列表示とし、各カードの高さを抑えています。

## 5. 計算ルール

タレント振り分け値と能力上昇値は一致します。

- 10振り → 能力+10
- 13振り → 能力+13

タレントポイントの消費ルールは変更していません。

- 1～4 → 1TP / 1振り
- 5～8 → 2TP / 1振り
- 9～12 → 3TP / 1振り
- 13～16 → 4TP / 1振り
