# eFootball タレントデザイン シミュレーター v2.4

## v2.4 変更点

- GK2 / GK3 のグローブアイコン内の数字を、パラメータ群名に合わせてそれぞれ「2」「3」に変更。GK1～GK3はグローブ＋白抜き数字で統一。
- 「能力 +0 / 消費 0TP」の表示を非表示化。
- 「能力配分」と「最終能力値」をスマートフォンでも左右に並べて表示。
- 能力配分は縦1列、最終能力値も指定順に縦1列で表示し、各カードの高さを圧縮。
- その他の計算ロジック・選手データ・ブースター設定は既存版を維持。

## GitHubへの反映

- index.html

`script.js`、`config.js`、CSV/JSONデータは変更していません。
