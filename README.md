# eFootball タレントデザイン シミュレーター

スマートフォンでの利用を優先した静的Webアプリです。HTML / CSS / JavaScript と CSV / JSON だけで動作します。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — スマートフォン優先のUI
- `script.js` — UI操作・計算ロジック
- `config.js` — パラメータ群・能力一覧・UI設定
- `players.csv` — 選手カードデータ
- `coaches.json` — 監督データ
- `coachAptitude.json` — 監督適性ルール
- `boosters.json` — ブースター対象能力
- `icons.svg` — パラメータ群アイコン（SVGシンボルを一括管理）

## GitHub Pagesで更新する場合

1. このフォルダ内のファイルをGitHubリポジトリの同じ階層へアップロード
2. Commitする
3. GitHub Pagesが自動で再デプロイするのを待つ
4. 公開URLを再読み込みする

既存のGitHubリポジトリにアップロードする際は、修正前のCommitを残してから新しいCommitを作ると、比較・復元がしやすくなります。
