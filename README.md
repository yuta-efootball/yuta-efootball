## v2.3 変更点

### 1. 不要な表示を削除
- ブースター各枠の「上昇値」という見出しを削除。
- 「通常ブースターは各枠ごとに+1～+4、追加ブースターは+1～+3、エッジブースターは+6を個別に選択できます。」という注釈を削除。
- 「能力配分」見出し下の説明文を削除。
- 各パラメータ群カードの「能力 +○ / 消費 ○TP」を削除。

### 2. アイコンの修正
- アイコンSVGを円形表示領域の中央に配置し、外側へはみ出さないように調整。
- シュートのアイコンは変更なし。
- フィジカルは、以前提供された上向き二重矢印アイコンを使用。
- GK1～GK3は、以前提供されたグローブアイコンを使用。

GK1～GK3については、今回の指定に従い、3枠すべて同じグローブ画像を使用しています。

## GitHubへの更新

1. ZIPを解凍。
2. 上記4ファイルだけをGitHubリポジトリへアップロード。
3. 同名の既存ファイルを置き換える。
4. Commitする。
5. GitHub Pagesの公開URLを再読み込みする。

選手データや計算ロジックを変更していないため、それらのファイルを再アップロードする必要はありません。
