# eFootball タレントデザイン シミュレーター v2.9.1

## 修正内容

### 計算順表示
画面上の計算順を以下の1行表示に統一しました。

**選手側ブースター → 上限 → 監督適性 → 監督ブースター**

### 選手スキル表示
`players.csv` の `skills` 列を選手情報欄に表示するよう変更しました。
スキルは縦並びで、スマートフォンでもコンパクトに確認できます。

### 能力配分リセットボタン
「配分をリセット」ボタンを画面右上から移動し、「能力配分」の右上側に配置しました。
フォントサイズは「能力配分」見出しより2pt小さくしています。

### 選手情報欄のTP表示
選手名欄に表示していた「TP」は削除しました。
能力配分欄の「残りポイント」で確認できます。

## 維持している内容

- 選手データはGitHub Pages上の `players.csv` を正本として読み込みます。
- `playerType` が「トレンド」の選手はタレントポイントを0として扱います。
- 監督・監督適性・ブースターは外部JSONを優先し、読み込み失敗時はフォールバックデータを使用します。
- `liveLinkTargets` 列は使用しません。
- 最終能力値カードの上下余白 `0.15em` を維持します。
