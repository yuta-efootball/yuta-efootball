### 2. 総合値
各TPカードの `overall` はGame8個別ページに掲載された「最大総合値」を使用しています。

### 3. 能力値
能力値はGame8個別ページの「初期値」を使用しています。育成後・TS適性後・最大能力値の値は初期値として使用していません。

### 4. 選手情報
利き足、身長、逆足頻度、逆足精度、調子の波、攻撃/守備プレースタイル、ブースター、選手タイプ、所持スキルを各個別ページで確認しました。ブースター未所持は `未選択` に統一しています。
