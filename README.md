## 修正内容

### 1. 配分をリセット
「配分をリセット」ボタンを「能力配分」エリアの右上へ移動しました。
スマートフォン表示では「能力配分」の見出しと同じ行の右側に表示します。

### 2. 計算順
計算順の記載が複数行に折り返されないよう、1行固定にしました。

### 3. 選手データ：総合値
`players.csv` に `position` 列の直後へ `overall` 列を追加しました。
今回の対象は、カードネームが `TP` で始まる12選手です。

総合値はGame8の各該当カードページに記載されている「最大総合値」を入力しています。
それ以外の既存CSV項目は変更していません。

### 4. スキル表示
v2.9.3までのスキル縦表示を維持しています。
