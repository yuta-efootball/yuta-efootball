# eFootball タレントデザイン シミュレーター v2.9.7

## 今回の修正

### 1. 4つの選手側ブースターの上昇幅ボタンを統一
通常ブースター①・通常ブースター②・追加ブースター・エッジブースターの上昇幅ボタンを、追加ブースターで採用していた仕様に統一しました。

- 押した値だけが有効
- 同じ値をもう一度押すと解除
- 別の値を押すと、前の値を解除して新しい値だけを選択
- 初期状態は上昇幅未選択
- 選択中のボタンは白色表示

通常ブースターは表示されている +1～+4、追加ブースターは +1～+3、エッジブースターは +6 を対象とします。

### 2. 計算順ボックス
「選手側ブースター → 上限 → 監督適性 → 監督ブースター」のボックスを、従来の横幅の2倍（グリッド2列分）にしました。
スマートフォンでは横幅いっぱいに表示します。

### 3. 配分をリセット
「配分をリセット」ボタンを「能力配分」エリアの右上へ配置しました。
スマートフォンでは「能力配分」と同じ行の右側に表示します。
これは添付されたv2.9.4の実装を維持しています。

### 4. 選手概要表示
選手概要のポジションと利き足は、不要な「ポジション：」「右/左：」を付けず、値だけ表示します。

### 5. 選手データ30件追加
添付されたplayers.csvの27件をベースに、TPカードを30件追加しました。

- 追加後：57件
- TPカード：42件
- 追加30件のcardNameはすべてTPで始まる
- cardName重複：0件
- 追加30件の必須データ空欄：0件
- 能力値25項目：すべて数値、40～99
- 総合値はGame8該当カードページの「最大総合値」
- 選手基本情報・特徴・ブースター・スキルはGame8該当カードページを確認したデータを使用
- 推測値による補完はしていません
